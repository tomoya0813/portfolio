# プロジェクト名
Cafe Lune

## 概要
夜のカフェをコンセプトに作成した、架空のカフェサイトです。

## Demo
公開URL: https://tomoya0813.github.io/portfolio/works/lune/index.html

## 制作背景
HTMLとCSSを学び終えて、実際に動くものを作ってみたいと考え制作をはじめました。

## ターゲット層
夜の落ち着いた雰囲気の中で、日常やSNSから少し離れて、自分の時間をゆっくり過ごしたい人を想定しています。

## 使用技術
- HTML
- CSS
- JavaScript

## 実装した機能
- 背景アニメーション
- ロゴ押下時のモード変化
- footerアニメーション

## 苦労した点
### HTML
PNG画像など容量の大きい画像を複数使用したため、サイト内画像の読み込みに時間がかかってしまいました。
制作中はキャッシュによって、この問題に気づけず完成後しばらくしてから実機確認をしているなかで発覚しました。

容量削減のため元画像の大きさをFigmaで調整し、Web上のtoolでWebpに変換しました。

### CSS
初めて大きなサイトを作ったということもあり、特にレスポンシブ対応で苦労しました。実際にどのようにしてレスポンシブを調整するのか理解する部分から始め、一つ一つ崩れがないかを確認していきました。

また、完成後も実機で見てみるとなぜか崩れていることが多発し、あとから直す部分が多くありました。

### JavaScript
今回の制作中ではまだJavaScript自体が学習途中だったため、学習していない内容についても必要に応じて調べながら実装しました。コードを書く中でわからない部分をどのように調べるかを身につけることができました。

## 工夫した点
内容部分を作り終えた段階では、テキストと画像を中心とした構成になっており面白みに欠けると感じました。
そこで、サイトの世界観をより楽しんでもらえるよう、以下の要素を追加しました。

- 背景アニメーション
- ライトモードへの切り替え
- footerアニメーション

単に情報を閲覧するだけではなく、サイトを操作すること自体にも「遊び」を感じられるよう工夫しました。

## 反省点
### CSS
sectionごとにCSSを適用した結果、コード量が多くなってしまいました。

共通の設定を用意することでより少ないコードで管理できたと考えます。

### JavaScript
マジックナンバーが多くなってしまい、可読性が低くなってしまいました。

数値を定数としてまとめるなど、後から見ても処理内容を理解しやすいコードにする必要があると感じました。

### 全体
制作前にサイト全体の構造やレイアウトを具体的に設計していなかったため、制作途中で構成を変更することが多く、制作期間が長くなってしまいました。

実装を始める前にワイヤーフレームなどを作成し、ある程度全体の構造を決めてから制作を進めることが重要だとまなびました。

## まとめ
今回の制作を通して、以下のことを学びました。

- 誰が見ても理解しやすいコード設計の重要性
- 開発前にワイヤーフレームなどで構造を整理することの重要性
- わからないことを自分で調べ、解決する方法
- 実機で確認することの重要性

初めて規模の大きいWebサイトを一から制作したことで、実装方法だけでなく、設計やデバッグ、問題解決まで含めたWeb開発の流れを経験することができました。
