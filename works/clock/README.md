# プロジェクト名
Create Clock

## 概要
オプション設定が可能なアナログ時計をHTMLに表示する、JavaScriptとCSSによるライブラリです。

## 開発期間
 1日

## Demo
公開URL : https://tomoya0813.github.io/portfolio/works/clock/index.html

## 制作背景
ポートフォリオ作成のなかで背景画像に動くアナログ時計を設置したいと思い、実験を兼ねて他ファイルで作成を進めていました。

直前にオプションのあるライブラリを使用していたこともあり、どういった処理をしているのか気になったことと、今後の作品制作でも使えるのではないか？と考え、一般化したものを作成しました。

## 使用技術
- HTML
- CSS 
- JavaScript

## 機能
- 時計機能
    - 現在の時刻を取得し、針の角度を計算
    - 秒針の表示の有無で描画更新時間を変更

- オプション設定   
    - 時計の縦横の大きさ設定
    - 時計内部の背景色設定
    - 各針の太さ及び長さ設定

## 苦労した点
### 設定反映
引数に変更したいオプションを与える形をとりましたが、ネストされたオブジェクトの設定をすべて指定しないと想定した挙動になりませんでした。そこでネストされた設定反映にnull合体演算子を用いて、
オプションが指定されている場合はその値を使用し、指定されていない場合はデフォルト値を使用するようにしました。

これにより、一部のオプションだけを指定しても、その他の設定を維持したまま時計を生成できるようにしました。

## まとめ
オプション設定を持つJavaScriptの処理を自分で実装することで、オブジェクトの扱いやデフォルト値の設定について理解を深めることができました。

また、単体で動作する処理を再利用可能な形に一般化することで、今後の作品制作でも利用できるようにしました。
